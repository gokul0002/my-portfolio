# Gokul Saran — Angular Portfolio

A responsive, interactive personal portfolio built with Angular 17, TypeScript and custom CSS.

## Features
- Responsive desktop/tablet/mobile layout
- Sticky navigation with mobile menu
- Dark/light theme toggle
- Animated hero section
- Interactive project carousel
- Skill progress cards
- Experience timeline
- Copy-email interaction
- LinkedIn CTA
- No external UI framework required

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Production build

```bash
npm run build
```

The production output is generated in:

```text
dist/gokul-saran-portfolio
```

## Personalization

Edit `src/app/app.component.ts` for:
- contact details
- projects
- skills

Edit `src/app/app.component.html` for page content and `src/app/app.component.css` / `src/styles.css` for styling.
